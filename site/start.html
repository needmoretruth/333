Take the program

333 is a small program you leave running on a computer you can spare, where it answers whenever another copy of it knocks; we call that keeping the vigil.

The file for that machine is 333-x86_64-linux. Light, the same client without the terminal screen, is 333-light-x86_64-linux. Both carry Tor.

On Linux or a Mac

In a terminal. The installer picks the file for the machine it runs on, checks it against the release's SHA256SUMS, and puts it at ~/.local/bin/333. It starts nothing and needs no password. Read it first; it is short.

curl -fsSL https://the333.dev/install.sh | sh

For Light, end it with sh -s -- --light in place of sh.

Or by hand, without the installer

The same steps, one at a time. The grep line prints OK before anything moves, and nothing after it runs if it does not.

cd "$(mktemp -d)"
base=https://github.com/needmoretruth/333/releases/latest/download
curl -fLO "$base/333-x86_64-linux"
curl -fLO "$base/SHA256SUMS"
grep -E ' \*?333-x86_64-linux$' SHA256SUMS | sha256sum -c - &&
  chmod +x 333-x86_64-linux &&
  mkdir -p ~/.local/bin && mv 333-x86_64-linux ~/.local/bin/333

That is Linux on x86-64. On a Mac, use shasum -a 256 in place of sha256sum, and the Mac file from the table below; anywhere else, the name from the table.

On Windows

In PowerShell. The installer fetches the Windows file, checks it against the release's SHA256SUMS, and puts it at %LOCALAPPDATA%\Programs\333\333.exe. It starts nothing, needs no administrator, and adds that folder to your PATH only if you add -AddToPath. Read it first; it is short.

irm https://the333.dev/install.ps1 | iex

For Light, run it this way instead. -AddToPath goes at the end in the same way.

& ([scriptblock]::Create((irm https://the333.dev/install.ps1))) -Light
Or by hand, without the installer

The same steps, one at a time. The file is moved into place only if its hash is the one SHA256SUMS gives, and the last line says which happened.

$base = "https://github.com/needmoretruth/333/releases/latest/download"
$file = "333-x86_64-windows.exe"
$dir = "$env:LOCALAPPDATA\Programs\333"
Invoke-WebRequest -UseBasicParsing "$base/SHA256SUMS" -OutFile "$env:TEMP\SHA256SUMS"
Invoke-WebRequest -UseBasicParsing "$base/$file" -OutFile "$env:TEMP\$file"
$want = (Select-String "[ *]$file`$" "$env:TEMP\SHA256SUMS").Line.Split(" ")[0]
if ((Get-FileHash "$env:TEMP\$file").Hash -eq $want) { New-Item -ItemType Directory -Force $dir | Out-Null; Move-Item -Force "$env:TEMP\$file" "$dir\333.exe"; "OK: $dir\333.exe" } else { "It does not match SHA256SUMS. Nothing was installed." }

Every file

For anybody the guess above is wrong for, or who would rather take the file through the browser. Standard has the terminal screen, Light does not, and both carry Tor. They run from 15 megabytes on a Mac to 24 on 64-bit ARM.

A file taken through the browser still has to be checked against SHA256SUMS, made executable, and put on your PATH, which is what the commands above do. Nothing here is signed by a developer certificate, so a Mac or Windows may refuse to open a file that came through the browser until you tell it otherwise. If none of these fits, or you would rather not run a file somebody else built, the repository says how to build it on Ubuntu, Debian, Fedora, Arch, macOS and Windows.

Then, in order

  1. Make a name. 333 id searches for a key whose name begins with 333, which takes a moment, and keeps it in this node's directory. It contacts nobody.
  2. Be handed the file. This site's node is awake at all hours: 333 join {{invitation}}. Or open the333.dev/333, take any address from the list, and run 333 join with it. It knocks on that one address and nothing else, and whoever is there hands the file over while the two of you sign for it. If the list is ever empty, somebody has to be first and it may as well be you: 333 bootstrap looks there, refuses if anybody is already waiting, and otherwise takes the file from this site and starts a line of your own, with nobody having signed for it, which anybody reading your record can see.
  3. Keep the vigil. 333 serve answers whoever knocks, on port 3333, for as long as it runs, and leaves the address a stranger could reach it at on the meeting point's board; --no-meet keeps it away from there. A home router usually drops what nobody inside asked for, so the node knocks on its own outside address when it starts and tells you which way it went. If it says shut, run 333 serve --tor instead: that needs no router touched, and the node builds its own way in from the inside out.
  4. Keep it running. A vigil that stops when you close the terminal is absent for every hour you are asleep. 333 service install asks this machine's own service manager to keep it running after the terminal is gone and to start it again when it stops, and 333 service uninstall takes that away again. This is the step we recommend next, and it is the one that decides whether you are counted.

Nothing starts until you start it.

The installer puts one file in place and runs nothing. 333 id makes a name and stops. Your node first answers anybody, and first leaves its address at the meeting point, when you run 333 serve or 333 service install yourself, and that command is the moment you agreed. The client writes down when your name was made, and 333 id tells you when you began.
