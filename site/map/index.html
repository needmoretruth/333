Where we are

Every node that says where it can be reached leaves that statement at the333.dev/333, and the request carrying it arrives from somewhere. This is that, counted. It is not a census: a node that was handed an invitation and never came here is not in it, and neither is one that told this place nothing.

A node reachable through Tor is counted as Tor and placed in no country. The request that carried its statement came from an ordinary address like everybody else’s, and that address is the one thing an onion address exists to withhold, so it is dropped here rather than stored.
