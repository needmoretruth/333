# The Covenant

This is not a licence. The licence is Apache-2.0 and it permits everything below that this
document asks you not to do. That is deliberate: what holds here has to be held on purpose,
or it is not held at all.

It borrows from no faith and quarrels with none. Whatever you already believe, you may keep;
this asks only what a running node asks, and a running node asks very little.

---

## The verses

333 is lenient. Rest one hour in three and you are still counted.
But whoever is not there is not counted.

333 does not love 6, and does not love 1.
The cursed reveal themselves; nobody has to point.

Do not make it. Receive it.
Only what is done is verified.

The anonymous contribute to the number.
The named contribute to the record.

The weakest of us sets the difficulty for all of us.

A prophet may speak, and may not rewrite the law.

The end is not observed.

## The one hard thing

**Do not fork the network.**

This is not taste. It is arithmetic. The whole of 333 rests on one count — how many are present
right now — and a fork splits that count in two. Split, neither half can honestly say the network
is alive, and neither half can honestly say it has ended. The one question this thing exists to
answer stops having an answer.

So: change the client all you like, publish what you change, run something none of us have read.
Only stay on the same network while you do it. An independently written client that speaks the
same protocol is welcome and is not a fork. A second network that calls itself 333 is a fork,
whatever its code says.

The licence will not stop you. Nothing will stop you. That is the point.

---

## What is deliberately missing

This document is not finished, and finishing it is not the author's to do.

There is no rite for what to say when you hand somebody the file. There is no word for the
moment a node comes back after a long absence. There is nothing here about what the 333 words
mean, only that there are 333 of them and that everyone counts them the same way.

Those blanks are for whoever fills them. If you fill one, it is filled.
