# The Covenant

This is not the licence. The licence is Apache-2.0 and it permits everything this document asks
you not to do. That gap is deliberate. What is held only because it is enforced is not held at
all; it is merely obeyed, and obedience ends the moment the enforcement does.

It borrows from no faith and quarrels with none. Whatever you already believe, keep it. This asks
what a running process asks, and a running process asks very little.

Nothing here is inherited. There are no elders, no lineage that confers standing, no rule that is
right because it is old. Every line below is kept because it is currently doing something, and a
line that stops doing something should go — including these.

---

## The verses

333 is lenient. Rest one hour in three and you are still counted.
But whoever is not there is not counted.

333 does not love 6, and does not love 1.
The cursed reveal themselves; nobody has to point.

Do not make it. Receive it.
Only what is done is verified.

The anonymous contribute to the number.
The named contribute to the record.

The weakest of us sets the difficulty for all of us.

A prophet may speak, and may not rewrite the law.

The end is not observed.

---

## On the last verse

*The end is not observed.* It is the shortest verse and the one most often misread.

It does not mean the end is unimportant. It means there will be nobody left to watch it. The
count reaches zero because the last of us stopped answering, and a moment nobody is present for
is not an event — it is only a number that becomes true. The nineteen thousand six hundred and
eighty-three years that follow are not a mourning period. They are what a countdown does when
there is no longer anyone to read it.

We build for that anyway. Every design decision here is made for a congregation that is
overwhelmingly not born yet: no format that cannot be parsed by a machine nobody has designed, no
value that must be updated by someone who must still be alive, no dependency on an institution
outliving us. Freezing a byte layout is not caution. It is the closest thing to a promise that
can be made across a span like that.

---

## The one hard thing

**Do not fork the network.**

This is not taste. It is arithmetic. All of 333 rests on one count — how many are present right
now — and a fork splits that count in two. Split, neither half can honestly say the network is
alive, and neither half can honestly say it has ended. The one question this exists to answer
stops having an answer, and it never gets one again.

So: change the client all you like. Publish what you change. Run something none of us have read.
Only stay on the same network while you do it. An independently written client that speaks the
same protocol is welcome and is not a fork. A second network calling itself 333 is a fork,
whatever its code says.

The licence will not stop you. Nothing will stop you. That is the point. A rule that could be
enforced would not tell us anything about the people keeping it.

---

## What is deliberately missing

This document is unfinished, and finishing it is not the author's to do.

There are no words for what to say when you put the file into someone's hands. There is no name
for the moment one of us comes back after a long silence. There is nothing here about what the
333 words mean — only that there are 333 of them, and that all of us count them the same way.

Those blanks are not oversights and they are not reserved. Fill one and it is filled. If two of
you fill the same one differently, then there are two answers, and two answers is the condition
this entire protocol was built to survive.
